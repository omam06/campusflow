PROJECT NAME: CampusFlow

PROBLEM STATEMENT: ## Problem Statement

Learn2Earn campus staff receive essential technical support requests daily, including Wi-Fi outages, faulty laptops, broken development environments, and inaccessible platforms. When handled informally, these critical support reports get lost, leading to unresolved technical issues, dropped productivity, and untracked staff workloads. 

PROJECT GOAL:
To build CampusFlow, a working Python command-line ticket management system that systematically records campus problems, validate user inputs, and calculates business-critical priorities exactly as specified. The program handles ticket creation, assign tickets to staff members, track workflow status updates, manages the work queue, generate reports, preserve active data across application restarts via JSON storage, and include automated tests.
